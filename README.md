# SmartChat – Full Stack Real-Time Chatbot

A syllabus-aligned learning project using React + Vite, React Router, Context API, Firebase Authentication, Cloud Firestore, Firebase Realtime Database presence, and a Node/Express REST API.

## Features
- Email/password registration and login with Firebase Authentication
- Public room and private one-to-one conversations
- Live message updates using Firestore `onSnapshot`
- Online presence using Firebase Realtime Database and `onDisconnect`
- Context API for authentication state
- React Router protected routes
- Express chatbot API with simple intent-based responses (no paid AI key required)
- Message history stored in Firestore

## Requirements
- Node.js 18+
- A Firebase project

## 1. Configure Firebase
In Firebase Console:
1. Create a project and register a Web App.
2. Enable **Authentication → Email/Password**.
3. Create a **Cloud Firestore** database.
4. Create a **Realtime Database**.
5. Copy the web app configuration into `client/.env` (create it from `.env.example`).

Example `client/.env`:
```
VITE_FIREBASE_API_KEY=...
VITE_FIREBASE_AUTH_DOMAIN=your-project.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=your-project
VITE_FIREBASE_STORAGE_BUCKET=your-project.firebasestorage.app
VITE_FIREBASE_MESSAGING_SENDER_ID=...
VITE_FIREBASE_APP_ID=...
VITE_FIREBASE_DATABASE_URL=https://your-project-default-rtdb.firebaseio.com
VITE_API_URL=http://localhost:5000
```

Apply the starter rules in `firebase/firestore.rules` and `firebase/database.rules.json` in the Firebase console. For a production app, tighten rules further and add App Check.

## 2. Install and run
From the project root:
```
npm install
npm --prefix client install
npm --prefix server install
npm run dev
```
Frontend: http://localhost:5173  
Backend: http://localhost:5000/api/health

## 3. How to use
- Register a new account, then sign in.
- Open **Public Room** to chat with all signed-in users.
- Open **Private Chat** and enter another user's exact email address.
- Select **Chatbot** to ask the built-in bot questions. The bot API is served by Express.
- The online panel displays presence for users who have the app open.

## Architecture
Browser (React UI) → Express `/api/bot` for chatbot replies  
Browser (Firebase SDK) → Firebase Auth, Firestore (messages), Realtime Database (presence)

Firestore collections:
- `users/{uid}` – profile data
- `rooms/{roomId}/messages/{messageId}` – messages

The public room ID is `public`. Private room IDs are deterministic from the two user UIDs.

## Deployment
- Deploy the `server` folder to Render. Set `PORT` if required. The server has no secret API key.
- Deploy `client` to Vercel. Set all `VITE_*` variables in Vercel project settings and set `VITE_API_URL` to your deployed server URL.
- Add your deployed frontend domain to Firebase Authentication authorized domains.
- Replace permissive development CORS settings in `server/index.js` with your exact frontend origin.
- Firestore and Realtime Database rules must be deployed before public use.

## Important
This is an educational chatbot starter, not a production AI assistant. Bot responses are generated by simple keyword/intent rules in the Express backend. You can later replace `getBotReply()` with an LLM provider, keeping the same `/api/bot` endpoint. Never put private API keys in React/Vite environment variables.
